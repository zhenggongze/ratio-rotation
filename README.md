# 比值轮动交易决策辅助系统

服务"创业板(399006)/中证红利(000922)比值轮动"策略的交易决策辅助系统。

## 系统定位

不连接券商、不自动下单，核心职责四件事：

1. **历史数据记录** — 每个交易日自动采集两指数行情，记录日别明细，按年汇总
2. **策略汇总** — 维护 20 档加仓/减仓操作表，每年 1 月 1 日自动检查档位参数
3. **每日操作提醒** — 每交易日收盘后（15:30）通过 PushDeer 推送精简文字提醒
4. **收益与数据可信度保障** — 内置收益自洽校验与数据双源交叉校验

## 策略核心

- **比值** = 创业板指(399006)收盘价 ÷ 中证红利(000922)收盘价
- **买入区**：比值 ≤ 0.332（历史 p6 分位），分批加仓创业板
- **滞回带**：0.332 < 比值 < 0.578，不操作（防磨损核心）
- **卖出区**：比值 ≥ 0.578（历史 p76 分位），分批减仓换红利
- **资金**：初始本金 160 万，20 档 × 8 万 = 160 万，每档 5% 仓位
- **交易时机**：T 日收盘信号、T+1 日开盘执行

- **主源**：腾讯行情 `https://qt.gtimg.cn/q=sz399006`
- **备用**：新浪 `https://hq.sinajs.cn/list=sz399006`
- **历史**：腾讯 `https://ifzq.gtimg.cn/appstock/app/fqkline/get`

### 中证红利（000922 + H00922）

- **价格指数**：中证指数官网 CSV 下载
- **全收益指数 H00922**：用于精确计算分红率（H00922 日收益 - 000922 日收益）
- **备用**：腾讯 `https://qt.gtimg.cn/q=sh000922`

### 双源交叉校验

- 主源与备用源差异 > 0.5% 判定异常
- 异常日标记待人工复核，不触发交易信号
- 比值超出 [0.28, 0.90] 区间告警

## V2 收益引擎

```
当日策略收益 = (1 + 隔夜段收益) × (1 − 调仓成本) × (1 + 日内段收益 + 分红计提) − 1

隔夜段收益 = 旧权重 × (创业板今开/创业板昨收 - 1) + (1 - 旧权重) × (红利今开/红利昨收 - 1)
调仓成本 = |新权重 - 旧权重| × 0.05%（单边），在 T+1 开盘扣除
日内段收益 = 新权重 × (创业板今收/创业板今开 - 1) + (1 - 新权重) × (红利今收/红利今开 - 1)
分红计提 = 新权重 × 创业板分红率 + (1 - 新权重) × 红利分红率
```

- 红利分红率：H00922 日收益 - 000922 日收益（精确），年均约 4.4%
- 创业板分红率：0.9%/252 兜底（无官方全收益指数）

## 收益自洽校验

- **恒等式 1**：期末总资产 ≈ 上期末总资产 × (1 + 当日收益率)，偏差 > 0.01 元告警
- **恒等式 2**：当日盈利 = 期末总资产 - 上期末总资产
- **恒等式 3**：(1+隔夜段)(1+日内段) - 1 ≈ 收盘/前收盘 - 1，偏差 > 0.0001 告警
- **朴素重算**：从头逐日循环不复用增量状态，最大差异 ≤ 0.01%

## 注意事项

- 所有策略参数以规格第二部分为准，不得自行优化或改动
- 推送必须纯文本、精简（≤150字）、必含：比值、是否操作、操作档位与金额、操作后创业板仓位
- 交易时机是 T 日收盘信号、T+1 日开盘执行
- 收益引擎必须精确复现 V2 开盘价模型
- 年度校准只建议不自动改参，防过度拟合
- 系统模拟仓与实际仓分离（双轨），用户实盘偏差必须记录
- 全程使用北京时间
